# 本地改动说明

本文记录相对于基线提交 `81eed5e` 的本地源码改动。

## 实时推理

- 索引返回不足 8 个邻居时，仅使用有效邻居进行加权混合；完全没有有效邻居的帧保留原始特征。
- 为零距离设置下限，避免索引加权除零。
- 区分索引率为零、索引未加载和检索失败的控制台提示。
- 音频回调通过事件队列发送推理耗时，由 GUI 主线程更新界面，避免跨线程调用 Tk。

## 启动优化

- 启动阶段缓存首次音频设备扫描结果，恢复配置时只重新筛选设备；手动刷新仍重新扫描。
- 检测到符合要求的 CUDA GPU 时跳过 DirectML 探测；无可用 CUDA GPU 或显式指定 `--dml` 时保留探测。
- 两个 Windows 启动脚本使用本机 Anaconda 的 `rvc` 环境；BAT 换行统一为 CRLF。
- WebUI 端口使用 `7865`，避免与本机代理端口 `7897` 冲突。

## 离线 WebUI

- 默认音色为 `CreatorV2.pth`（文件存在时），单次和批量推理默认变调均为 `11`。
- 默认检索路径为 `E:\PyProject\RVC\logs\CreatorV2.index`。
- 页面加载时初始化选中的模型，避免只选中音色却未加载推理管线。
- 空说话人下拉框回退到滑块值，均为空时使用说话人 `0`。
- 仅过滤 Windows Proactor 关闭连接回调中的 `ConnectionResetError` / `WinError 10054`，其他异步异常仍正常报告。
- 将离线推理的成功摘要与失败详情同时输出到控制台。

## 本机配置与提交范围

- 启动脚本当前使用 `D:\AppData\anaconda3\envs\rvc`。在其他电脑使用时需要调整脚本中的 `RVC_ENV`。
- 默认音色与索引是个人配置，模型和索引文件需自行准备。
- `.gitignore` 排除模型权重、训练音频、训练日志、推理输出、Python 缓存、IDE 配置和本机工具。
- `configs/config.json` 已由上游跟踪，本次保留其本机改动但不提交；忽略规则不会影响已跟踪文件。
- 分离模型 YAML 的纯换行改动不纳入本次提交。
- 本次未改动模型训练算法，未将训练数据或权重上传到仓库。

- Python 源码语法检查。
