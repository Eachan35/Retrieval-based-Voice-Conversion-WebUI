# 实时动态音高压缩

运行原来的 `go-realtime_gui.bat`。新增“动态音高压缩”设置，默认开启，参数为 450 Hz 阈值、2:1 压缩比、4 半音软拐点、30 ms 平滑。

这些参数源于离线对照实验的起始设置，不是模型的通用安全上限。正常说话不应明显改变音色；激动高音刺耳时再对比开关效果。

修改压缩开关或参数后，音频流会停止，需要重新点击“开始音频转换”。开始时随原有设置保存到 `configs/config.json`。旧配置缺少这些字段时自动使用默认值，不改写模型和索引路径。

- 阈值：变调后的目标音高，从这里附近开始压缩。
- 压缩比：2 表示软拐点之外，原本升高 2 半音，实际只升高 1 半音；1 表示不压缩。
- 软拐点：阈值附近的平滑过渡宽度，略低于阈值也可能少量压缩。
- 平滑：因果一阶滤波的时间常数，不是额外音频缓冲延迟；过大会让压缩响应变慢。

## 实现边界

离线使用双向高斯平滑，实时无法读取未来帧，改用因果一阶平滑，两者听感不保证完全相同。不增加额外音频块，但有少量计算开销。

每次提取的重叠 F0 先写入未压缩的历史缓存，压缩从原始缓存重新计算，避免重复处理同一帧。连续 F0 和离散音高编码同步更新。原有声线粗细的重采样因子会用于补偿 Hz 阈值。

新流使用新缓存；CUDA Graph 预热结束会清空原始和压缩后的音高缓存。关闭开关保留原音高处理行为，其他直接使用 RVC 类的入口默认关闭，不受 GUI 默认开启影响。

没有情绪识别、八度纠错或削波修复。原实时管线的无声帧插值仍然保留，因此压缩器只会对仍为零的 F0 重置平滑，不将插值后的帧当作可靠有声判断。

验证包括缓存重叠、关闭回归、压缩比 1、因果性、静音与重置、配置兼容性，以及真实模型的分块推理。文件回放无法代替麦克风、设备驱动和完整音频回调的现场测试。
